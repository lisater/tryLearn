# tryLearn - одностраничный сайт для лабораторных работ

## Live Demo
https://lisater.github.io/tryLearn/ 

## Идея
На Stepikе есть такой тип задания, в котором необходимо написать свой код, отправить его на проверку, и в интерактивном режиме получить ответ. Покажут и результат выполнения кода, и ошибки, и "правильное решение" когда всё получится.  
Мне понравился такой тип задания, и возникла мысль сделать такое же. Но создавать там свой курс или искать другой сайт с подобным функционалом это долго, нудно, надо регистрироваться... Поэтому я решила сделать свой. :)  
Без рекламы, лаконичный, можно настроить под себя.

## Разработка
Очевидно что в век ИИ-технологий намного проще и удобнее делать лёгкие проекты при помощи нейросети. Именно так я и сделала - описала свою идею DeepSeek и он написал мне index.html (самый первый коммит) и опубликовала при помощи GitHub Pages. Конечно же, с первого раза ничего как нужно не сработало - пришлось править.  
Путём различных экспериментов был создан именно такой сайт, который использует нужные ему утилиты загружая их из репозитория, а не ищет их в Интернете. Это помогает избежать огромного множества проблем с блокировками, медленной загрузкой и так далее.

## Инструменты
Сайт использует две вспомогательные библиотеки: **Ace Editor** и **Skulpt**.  
- **Ace Editor** - полноценный редактор кода с открытым исходным кодом, написанный на JavaScript. В данном случае настроен под python, фактически превращает "окошко для написания кода" в "мини-версию IDE" на манер PyCharm и VS Code. Ace подсвечивает синтаксис, показывает подсказки, нумерует строки, предлагает автодополнение и др.  
Файлы взять здесь: https://github.com/ajaxorg/ace-builds  
- **Skulpt** - браузерный интерпретатор Python, написанный на JavaScript. Он позволяет запускать код пользователя прямо в браузере "на стороне клиента" без дополнительных ухищрений. Поддерживает весь базовый синтаксис Python + все стандартные модули.  
Файлы взять здесь: https://github.com/skulpt/skulpt-dist  

## Автотесты
Ради них всё и затевалось.  
Тесты прописываются в JavaScript-переменной `fullCode` в виде стандартных проверок Python:
   ```python
   assert my_function(test_input) == expected_output, "Описание ошибки"
   ```
Работает это таким образом: берётся код пользователя, к нему в конце "приклеиваются" проверочные команды. Всё вместе запускается и далее Python либо выдаёт ошибку, если хоть одна проверка проваливается, или выдаёт сообщение о том что всё хорошо.
